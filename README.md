# 🍔 Burger House — Front-End Project

A modern, responsive restaurant website built with **HTML, CSS, JavaScript, Bootstrap 5, and TheMealDB API**.

The project focuses on creating a complete and interactive restaurant experience with dynamic menu content, search and filtering, product details, order validation, and responsive design.

## 🌐 Live Demo

**[View Burger House Live](https://rehab2905.github.io/Burger-House-/)**

## ✨ Features

* 📱 Fully responsive design
* 🧭 Responsive sticky navigation
* 🍔 Hero section with call-to-action
* ⭐ Popular picks
* 📖 About / brand story
* 🍽️ Dynamic menu using TheMealDB API
* 🔎 Menu search
* 🏷️ Category filtering
* ➕ Load More functionality
* 🛒 Interactive product details modal
* 🎁 Special offers section
* 📊 Restaurant statistics
* 🖼️ Image gallery
* 💬 Customer testimonials
* 📝 Order form with validation
* 🔔 Success toast notifications
* ✨ Scroll reveal animations
* 📱 Mobile-friendly layout
* 🔄 API fallback menu when the API is unavailable

## 🛠️ Technologies

* **HTML5**
* **CSS3**

* **Bootstrap 5**

* **Font Awesome**

## 🔌 API Integration

The website integrates with **TheMealDB API** to dynamically load meal data and display it within the restaurant menu.

A fallback menu is also implemented to ensure the website remains functional if the API is unavailable.

## 🎯 Project Goal

This project was created to practice building a complete **responsive and interactive Front-End website**, with a focus on:

* Clean and modern UI
* Responsive layouts

* API integration
* Form validation
* User experience

## 🚀 Run Locally

1. Clone the repository.
2. Open the project in **Visual Studio Code**.
3. Run the project using **Live Server**.
4. Open `index.html` in your browser.
