# 🍔 Burger House

A modern and responsive restaurant website designed to deliver a smooth and engaging online food-ordering experience.

## ✨ Features

* Responsive design for all screen sizes
* Modern and attractive restaurant UI
* Interactive navigation
* Menu and food categories
* Special offers section
* Restaurant gallery
* Contact section
* Order Now call-to-action
* Smooth and user-friendly experience

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Bootstrap
* Font Awesome

## 🎯 Project Goal

The project was created to practice building a complete responsive restaurant website while focusing on clean UI, usability, responsiveness, and interactive frontend elements.
